### 通用技术规格
- 背景：**统一深色纯色背景 `#1a1a2e`（深蓝紫）**，不画底纹、渐变、棋盘格。
- 角色：竖构图 1:1.5，全身入画，脚底对齐画面底边，**人物占满画布为主体（占画面高度约 95%）**，左右仅留极小安全边距；背景统一纯色 #1a1a2e（不画底纹/渐变/棋盘格）。
- 道具：正方形或 1:1.2，主体居中，四周留白。
- 地砖：1:1 正方形，无缝可平铺，正俯视，**满幅不透明贴图**（不适用背景规则）。
- 所有素材：不画地面阴影（阴影由引擎实时投射），画面内不含任何文字/色号。
- 入库前统一抠图：深色底出图 → remove.bg / PS「选择主体」去背景 → 导出 PNG-24 带 alpha（引擎 Sprite 需要透明通道）。

### 过审避坑（提示词被平台拦截时用）

> **本文件所有提示词正文已完成平替**（药瓶→玻璃小瓶、药水→魔法瓶、液体→实心玻璃、女巫→秘法师、骷髅→骸骨、地狱犬→烈焰魔犬、血滴→绯红雾滴）。小节标题与 `entityKey`（如 `po_holy`、`npc_witch`）为游戏内命名，不送审、不要改动。

高频被拦组合（国内平台：即梦 / 通义万相 / 豆包 / 文心）：

- `药瓶`、`药水`、`圣药`、`potion` → 命中药品 / 管制词库。**去掉「药」字**是最有效的一刀。
- `粉红 / 白色液体 + 玻璃瓶` → 易被图像审核误判为不雅内容（真实存在的误判，和提示词本身无关）。
- `瓶内 + 凝胶/液体 + 悬浮微粒/光点` → 易被判为不明液体 / 危险品。**单纯换词没用**（「凝胶」「发光物质」在语义上仍是液体），必须取消「容器 + 内容物」这个结构。

对策顺序：① 改描述结构（取消容器/内容物二分，见下「实心彩色玻璃法」）→ ② 换容器名（香氛瓶借壳）→ ③ 空瓶法 + 后期填色 → ④ 换语言（中文 ↔ 英文，两套词库不同）→ ⑤ 换平台（各家尺度不同）。

替换表：

| 原词 | 替换 |
| --- | --- |
| 玻璃药瓶 / potion bottle | 玻璃小瓶 / small glass vial |
| 药水 / potion | 魔法能量瓶 / glowing magic vial |
| 瓶内液体 / liquid inside | 实心玻璃内部渐变 / gradient inside solid glass |
| 粉红液体、凝胶 / pink gel | 实心粉红半透明玻璃 / solid translucent pink glass |
| 悬浮微粒、光点、气泡 | **直接删除，不要替换** |

**方案 A·实心彩色玻璃法**（推荐，一次出图、无需后期填色）：

把「瓶 + 内容物」合并成一个实心玻璃物件，从根上消除液体概念：

- 改前：`玻璃小瓶，瓶内粉红发光凝胶，悬浮微粒与光点`
- 改后：`实心粉红半透明玻璃小瓶，玻璃内部呈粉红渐变与棱面折射`
- 保留：`实心`、`一体成型`、`内部渐变`、`棱面折射`、`硬边高光`
- 删除：`瓶内`、`发光`、`凝胶`、`悬浮微粒`、`光点`、`气泡`

**方案 B·香氛瓶借壳法**：把 `玻璃小瓶` 换成 `香氛瓶 / 香薰瓶 / 香水瓶`（合法日用品，瓶型几乎一致），其余描述不变；与方案 A 叠加效果最稳。

**方案 C·空瓶法**（最稳，几乎必然过审，但需 PS 后期填色）：

1. 只生成空瓶：「正面玻璃小瓶，厚壁瓶身，软木塞，瓶内无内容物，玻璃边缘折射与硬边高光。2.5D 精细矢量插画，多层明暗+细描边，冷暖对比布光，暗部深沉，通透玻璃质感。深色纯色背景 #1a1a2e，居中，正方形 1:1」
2. 出图后在 PS 新建「填色」图层，按品质填 `#dd6688` / `#ee3344` / `#bb1133` / `#990033` / `#ffdd44`，叠加外发光。
3. 一张瓶身复用 5 档魔法瓶，风格 100% 统一，出图成本降 80%。

## 各工具参数建议

- 即梦 / 通义 / 豆包：提示词写「深色纯色背景 #1a1a2e」；若出图仍是白底，改写成「纯色背景（纯白或纯洋红 #ff00ff）」再一键抠图；尺寸选 1:1 或 3:4；风格选「插画 / 平涂」。
- Midjourney：原生不支持透明，末尾加 `--no background, checkerboard, text, watermark --style raw --s 50`，出纯色底后抠图；按需加 `--ar 1:1` 或 `--ar 2:3`。
- Stable Diffusion / SDXL：负向框整段贴入「通用负面提示词」英文；采样器 `DPM++ 2M Karras`；步数 28-35；CFG 6-8；分辨率 768×768 或 768×1152；要真透明可挂 `LayerDiffuse` 插件。

## 抠图与导出规范

- 目标格式：**PNG-32 位（带 alpha 通道）**，禁止 JPG（无透明通道）。
- 三种拿法（按工具能力从优到次）：
  1. 工具直接支持透明导出（SDXL + LayerDiffuse、即梦「抠图」）→ 直接出 PNG-32。
  2. 工具只能出纯色底 → 本项目统一用深色 `#1a1a2e` 出图；若抠图后边缘残留暗边，改用「纯洋红 #ff00ff」重出再抠。出图后用 remove.bg / 即梦抠图 / PS「选择主体」去掉背景。
  3. 已有白底图 → PS「选择 > 色彩范围」选白底删除，羽化 1px 去除白边。
- 质检：放大到 400% 看边缘，不得有白色描边残留、半透明灰边、棋盘格底纹。
- 画布统一：同类素材尺寸一致（角色 768×1152、道具 768×768、地砖 512×512），主体居中，边缘留 2-3px 安全边距。
- 命名：`类型_品质_名称.png`，如 `equip_mythic_sword.png`、`po_holy.png`、`npc_witch.png`。

## 接入说明

- 命名建议与 `entityKey` 对齐，便于直接替换 `TextureGenerator.entity()` 的缓存键：如 `n_npc_witch`、`po_holy`、`cauldron`、`shelf`、`fountain`。
- 动态实体替换时，将对应 `case` 分支的 Canvas 绘制改为 `THREE.TextureLoader` 加载本目录素材，其余逻辑不变（见技术方案 §5.4）。
