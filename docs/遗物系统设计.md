## 一、系统概述

### 1.1 定位
遗物是爬塔过程中的**永久增益载体**：一旦获得，在本轮爬塔内持续生效，直至本轮结束。
与装备的区别：
- **装备**：有品质（破烂→神话七档）、可替换、占槽位、侧重数值成长。
- **遗物**：无品质档位、只按稀有度分级、**不可主动卸下**（获得即绑定）（但是可以在获取时选择丢弃）、侧重**机制改变与化学反应**。

### 1.2 设计基调
- 强力遗物应当**非常稀有**；
- 允许存在**看起来没什么大用**甚至**纯趣味**的遗物（这是 roguelike 收藏品的乐趣）；
- 关键在**组合质变**：单独平平无奇的几件遗物凑齐后产生质变效果；
- 允许**负面/诅咒遗物**：代价明显，但收益足以让某些 build 成立。
- 稀有度颜色为（-1到4）：深红（边框闪烁），灰色，蓝色，紫色，红色（鲜艳），彩色（渐变，同时存在2种颜色）

### 1.3 获取方式（建议）
全局遗物获取概率（每个稀有度独立概率，同时判定，允许同时获得多个，当然要你运气极好）（除特殊说明）：0：5%，1：3%，2：1%，3：0.5%，4：0.2%。
- 宝箱（普通/精英房）
- Boss 击杀掉落（必定掉落遗物，遗物基础概率（普通难度第五层boss）（从0到4）：50%，30%，18%，2%。（概率会随着楼层的深入与难度的增加而增加））
- 精英怪低概率掉落
- 商人处金币购买（价格随稀有度超大幅度递增）（商品遗物出现的稀有度与boss同理）
- 特定楼层（如区段起点 1/16/41/61/81/101）的楼层奖励（暂不考虑）
- [待定] 女巫/铁匠处的特殊兑换或重铸
-其他特殊获取方式（事件等）

## 二、稀有度体系

| 数字 | 稀有度 | 说明 |
|---|---|---|
| -1 | **灾厄造物** | 负面向。开局灾厄 / 高风险中收益 / 事件型灾厄（可净化）。**见 §4.8**。 |
| 0 | **尘芥** | 最低正向档。趣味物品与"只给一点点数值"的微末之物。收藏与彩蛋的载体。**见 §4.6**。 |
| 1 | **尘世遗物** | 最常见。效果直白、数值较小。是 build 的地基。 |
| 2 | **圣遗物** | 中等稀有。效果具备**机制性**（条件触发、资源转换、特殊规则）。 |
| 3 | **神祇遗物** | 稀有。效果强力或独特，常带有**代价**，或是质变组合的核心件。 |
| 4 | **天堂** | 传说档，预留未设计。见 §2.1。 |

> 完整梯度：**灾厄造物(-1) → 尘芥(0) → 尘世(1) → 圣(2) → 神祇(3) → 天堂(4)**

### 2.1 传说稀有度：**天堂**（⚠️ 占位 / 测试用）
- **状态（2026-09-10 更新）**：已加入 2 件天堂遗物，**均为占位 / 测试用，暂不提供常规获取途径**（`dropChances["4"] = 0`，仅可通过调试控制台获取：`~` → 勾选「点亮所有图鉴」→ 在遗物图鉴中点击取得）：
  - `H001 荡魔义旗`：每击杀一名敌人攻击力 +2%（本轮累积）—— 已接入 `RelicManager` 击杀钩子与 `snapshot()`。
  - `H002 赫尔墨斯双蛇杖`：每战用药资格 +1（合计 2 次）—— 效果已随「每战一次用药资格」规则生效。
  - 配套：`rarityNames` / `rarityColors` 与图鉴「天堂遗物」分区已就绪；`bossDropChances` / `eliteDropChances` / `merchantPrices` 无 `"4"` 档。
- **设定占位**：天堂是传说中的第四档稀有度，其遗物只能在通过完成游戏内成就等后才可以通过常规掉落获得。
- **与主线关联**：本作核心反转是「**天堂在地下**」——塔顶为假终点，真正的天堂位于塔基之下的最深处。因此**天堂遗物**在设定上应只在**真结局 / 地下天堂层**路径中解锁，或作为多轮爬塔的元进度奖励。
- **实现预留**：稀有度枚举与 UI 已支持 `4 = 天堂` 展示（图鉴已有「天堂遗物」分区）。
- **后续**：更多天堂遗物（尤其与「天堂在地下」真结局绑定的）待地下篇设计时再补。

## 三、上下位机制

> ⚠️ **实现状态：⏸ 暂不实现（保留构想）** —— 进阶系统当前不纳入开发，仅作设计储备。详见 §3.1。

### 3.1 概念
部分遗物存在**进阶链**：下位遗物在特定条件下（如到达指定楼层、完成特定事件、或集齐材料）**进阶为上位遗物**，原下位消失、上位继承并强化其效果。也有部分上下位的遗物可以共存（通常效果比较简单，效果可以累加）（目前不考虑进阶遗物，不过想法可以，保留想法）

### 3.2 设计意图
- 让「尘世遗物」在后期仍有价值（可进阶，而非沦为废品）；
- 为稀有度分配提供**天然梯度**：同一条链上，下位 → 中位 → 上位 应对应 1 → 2 → 3。

## 六、实现备注（供后续开发）

### 6.1 建议数据结构（`src/data/relics.json`）
```json
{
  "id": "R001",
  "name": "锈剑「无名」",
  "rarity": 1,
  "category": "combat",
  "desc": "攻击 +3",
  "combos": [],
  "effects": [{ "type": "stat", "stat": "attack", "value": 3, "mode": "flat" }],
  "note": "剑链·下位（进阶暂不实现）"
}
```
```json
{
  "id": "X021",
  "name": "断裂的圣徽",
  "rarity": -1,
  "subtype": "event",
  "category": "risk",
  "desc": "防御 -10%",
  "effects": [{ "type": "stat", "stat": "defense", "value": -10, "mode": "percent" }],
  "purifyTo": "X021P",
  "note": "C 类·事件型灾厄（可净化）"
}
```
- `rarity` 用整数：`-1`（灾厄造物）/ `0`（尘芥）/ `1`/`2`/`3`，预留 `4`（天堂）。
- `effects` 用**声明式**描述，避免在代码里写死每件遗物的逻辑。
- `combos` 记录参与的质变组合 id（进阶链暂不实现，故无 `chain` 字段）。
- `note` 记录备注（进阶链 / 组合名 / 来源）。
- `icon` 可选（emoji 或图片路径），缺省按类别给默认 emoji。
- `tbd` 标记稀有度 / 数值未定（如 C 类净化形态）；`exclusive` 标记专属遗物（不进随机掉落池）。
- `desc` 为遗物描述文案（可由设计者填写，或由 AI 根据其「描述」列的提示词/概念生成）。
- **灾厄造物专属字段**：
  - `subtype`：`start`（A 类开局灾厄）/ `risk`（B 类高风险中收益）/ `event`（C 类事件型）。
  - `purifyTo`：C 类的**专属净化目标 id**（一对一，不可交叉）；A/B 类留空。
  - 净化后的遗物作为**独立条目**存在于同一张表（id 形如 `X021P`），当前 `rarity` 定为 `2`（带 `tbd`，待最终确认）。

### 6.2 效果类型（与代码一致）
`stat`（属性加减/百分比）、`passive`（常驻规则/属性）、`onLowHp` / `onHighHp`（低血 / 高血条件 + stat）、`onKill`（击杀触发，`action`：`heal` / `healPct` / `loseHp` / `killGold` / `killAttackPct`）、`onFloorEnter`（进层触发，`action`：`heal` / `healPct` / `key` / `hpLossPct`）、`none`（趣味类）。

### 6.3 UI / 展示
- **遗物栏（已实现）**：屏幕上方的**横向图标条默认折叠为一行**；鼠标移上去时**按需展开**（`max-width` / `max-height` 过渡，动画流畅），顺序为「**点 → 线 → 面**」——先在一行内**向右**延伸，一行放不下才**换行、整体向下**扩展；右侧预留小地图宽度，故不遮挡其他部件。鼠标悬停任一图标弹出**悬浮窗**（`#relic-tooltip`）显示名称 / 稀有度 / 效果 / 备注。展开期间，进层提示（`#floor-tip`：「进入【…】」/「第 N 层」）**自动透明**以免遮挡图标，鼠标移开后恢复。
- **左栏持有详情（已实现）**：左栏以**长方形卡片**（`.relic-card`）列出当前持有的遗物，**直接显示效果文字**（图标 + 名称 + 稀有度 + 效果），标题栏可点击**折叠 / 展开**（折叠状态为会话级）。
- **获取抉择（已实现）**：掉落 / 开箱**发现遗物**时弹出获取界面（`ui/RelicChoicePanel.ts`），展示名称 / 稀有度 / 效果 / 备注，玩家选择「**收下**」或「**丢弃**」；丢弃则不入账。掉落路径改为 `RelicManager.offer()`（只广播、不入账），玩家确认后由 UI 调 `add()` 正式入账；开局专属 / 难度灾厄仍为静默直接获得。
- **遗物宝箱（已实现）**：**每个区段的最后一个 Boss 层**（第 **15 / 40 / 60 / 80 / 100** 层，即下一层为新区段起点者）的**终点房必定生成**一个「遗物宝箱」（紫色箱体，`chestTier: 'relic'`，见 `ContentFiller.relicChestSpot()`）；开启后弹出**三选一**界面，从 3 件候选中挑选一件带走（`RelicManager.randomCandidates(3)`：排除专属 / 未定稿 / 已持有，稀有度带权重）。
- **遗物不可售卖 / 回收（已实现约束）**：商人「老古」与女巫「薇薇安」**均不出售遗物**，玩家也**不能出售遗物换金币**——`ShopEntry` 不含 `relic` 类型、`relics.json` 已移除 `merchantPrices`，遗物面板只提供「丢弃 / 净化」。遗物仅能通过掉落、开箱与遗物宝箱获得。
- **遗物图鉴（已实现）**：默认**收录全部遗物**（含专属 / 初始 / 天堂遗物），按稀有度分区（天堂 / 神祇 / 圣 / 尘世 / 尘芥 / 灾厄造物）陈列名称、图标、效果、描述与所属；未获得的以暗色 + 「未获得」标注区分，**不再隐藏为 ？？？**；专属遗物额外标注「专属」。调试控制台「点亮所有图鉴」开启后，可点击未获得条目直接获取。
- 稀有度用**颜色/边框**区分：灾厄造物（暗红/黑，带裂纹）、尘芥（灰褐）、尘世（灰白）、圣遗物（金）、神祇（紫/彩）、天堂（预留，暂不出现）。
- **灾厄造物建议单独分区展示**（负面栏），与正向遗物视觉隔离，避免玩家误以为是增益。
- C 类灾厄在其图标上标记"可净化"提示（如锁链图标），净化后该条目替换为净化形态。
- 质变触发时应有显著提示（如"血怒已觉醒"）。
